# KYC Document URLs

The following new fields are now supported in the backend:

```js
cancelChequeUrl
bankStatementUrl
passbookUrl
```

All uploaded files (PDF/Image) are served from:

```text
https://shadily-hazard-widget.ngrok-free.dev/kyc-docs/
```

Example:

```text
https://shadily-hazard-widget.ngrok-free.dev/kyc-docs/passbook-172839.pdf
```

These URLs work exactly like existing Aadhaar/PAN/Selfie document URLs.

# 2 — Get All KYC Submissions

**Method:** `GET`

```text
https://shadily-hazard-widget.ngrok-free.dev/api/admin/kyc/all-submissions
```

### Headers

```text
Authorization: Bearer <admin_token>
```

### Response Includes

```json
{
  "_id": "kyc_id",
  "fullName": "Nithin",
  "status": "under_review",

  "aadharFrontUrl": "https://...",
  "panCardUrl": "https://...",
  "passportUrl": "https://...",
  "selfieUrl": "https://...",

  "cancelChequeUrl": "https://...",
  "bankStatementUrl": "https://...",
  "passbookUrl": "https://..."
}
```

# New Backend Fields Added

These are the exact field names added by backend:

```js
cancelChequeUrl
bankStatementUrl
passbookUrl
```

Frontend can directly use:

```js
kyc.cancelChequeUrl
kyc.bankStatementUrl
kyc.passbookUrl
```

These fields may be:

```js
null
```

if the user has not uploaded that document yet.
