# Admin Authentication APIs

## 1 — Admin Login

**Method:** `POST`

```text
https://shadily-hazard-widget.ngrok-free.dev/api/admin/auth/login
```

### Request Body

```json
{
  "email": "admin@example.com",
  "password": "password123"
}
```

or

```json
{
  "mobile": "9876543210",
  "password": "password123"
}
```

---

## 2 — Create Sub Admin

**Method:** `POST`

```text
https://shadily-hazard-widget.ngrok-free.dev/api/admin/auth/create-admin
```

### Headers

```text

```

### Body

```json

  "name": "Operations Admin",
  "mobile": "9876543210",
  "email": "ops@payo.com",
  "password": "Password123",
  "adminRole": "operations_admin"
}
```

# Authentication

All protected APIs require:

```text
Authorization: Bearer <admin_token>
```

The token is returned from:

```text
POST /api/admin/auth/login
```

and contains:

```json
{
  "id": "user_id",
  "role": "admin",
  "adminRole": "kyc_admin"
}
```

or

```json
{
  "id": "super_admin",
  "role": "admin",
  "superAdmin": true,
  "adminRole": "super_admin"
}
```
